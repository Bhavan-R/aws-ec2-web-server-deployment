Project Overview

This project walks through launching a virtual server in AWS, configuring access securely, installing a web server, and publishing a simple website accessible through a browser.

Identity & Access

Explore IAM users, groups, roles, policies, and permission boundaries. Follow least-privilege access practices.

Compute

Launch and configure a Linux virtual machine using Amazon EC2.

Network Security

Use a security group to control inbound and outbound traffic to the instance.

Web Hosting

Install a web server and serve a basic HTML page from the EC2 instance.

AWS Services & Concepts

IAM

Identity and Access Management controls who can access AWS resources and what actions they can perform.

Amazon EC2

Elastic Compute Cloud provides resizable compute capacity in the cloud through virtual server instances.

Security Groups

Instance-level virtual firewalls that regulate network traffic using rules.

Apache Web Server

HTTP server software used here to serve the website to visitors.

Deployment Flow

The following summarizes the intended deployment workflow.

01 · IAMReview identities and permissions. Use secure access and least privilege.
02 · EC2Launch a Linux instance and select an appropriate instance type.
03 · Security GroupAllow SSH only from your IP; allow HTTP traffic for website access.
04 · Web ServerInstall and start Apache, then place the website files in its document root.
05 · VerifyOpen the instance's public IPv4 address in a browser and confirm the site loads.
